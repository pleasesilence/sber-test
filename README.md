
## Установка

Скачайте содержимое проекта, затем запустите команду `docker compose build && docker compose up -d`. В браузере он будет на интерфейсе `localhost`.

## Тесты

Для того, чтобы запустить тесты, запустите `make run-unit-tests`. Обратите внимание, что тесты будут работать только в том случае, если запущен compose.
